Wave Foam Shader is a stylized water shader built to sit in a game that has static objects sitting in the water. 

- Badges:
  - Unity [blue]
  - Shader [blue]
  
## Customization options
Artists can set these to fit their needs:

- wave and foam speed, color, and direction
- foam distance and intensity
- refreaction shinyness
